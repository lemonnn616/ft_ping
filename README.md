# ft_ping

Implementation of the ping command in C.

42 School / Codam — ft_ping v5.1

## Environment
- Debian 12
- Oracle VirtualBox
- GCC
- Linux IPv4 raw sockets

## Project
- Mandatory part: ICMP Echo Request/Reply
- Bonus part: additional ping options

## Build
make

## Run
sudo ./ft_ping 127.0.0.1
